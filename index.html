上海中考升学路径体系

初中毕业后，考生可选择普高路径或中职路径，三条主线最终均可通向本科/专科

初中毕业（参加上海中考，满分750分）

路径一：普通高中 → 高考

自主招生 → 名额分配到区 → 名额分配到校 → 1-15志愿统一录取
自主招生
市重点高中+特色高中提前选拔。2025年控分线：605分。
适合：综合素质优秀控分线：605
名额分配到区
市重点将名额分配到各区，按区内排名录取。2025年控分线：605分。
适合：区内排名靠前控分线：605
名额分配到校
市重点将名额分配到各初中学校，校内竞争。2025年控分线：605分。
适合：校内排名靠前控分线：605
1-15志愿统一录取
最多填报15个平行志愿，按分数从高到低录取。2025年控分线：513分。
适合：所有考生控分线：513
→ 高考 → 本科 / 专科（3年高中 + 4/3年大学）

路径二 & 路径三：中职校 → 升学/就业

中本贯通（3+4）
3年中职 + 4年应用型本科，毕业获全日制本科文凭。2025年76个专业，最高分677分。
适合：513-677分学历：本科控分线：513
五年一贯制
同一高职院校连续培养5年，毕业获全日制大专文凭。2025年69个专业。
适合：400分以上学历：大专控分线：400
中高职贯通（3+2）
3年中职 + 2年高职，毕业获全日制大专文凭。2025年208个专业。
适合：400分以上学历：大专控分线：400
普通中专 / 职校 / 技校
3年制，可参加三校生高考升本科/大专，也可直接就业。2025年控分线350分。
适合：350分以上学历：中专→可升控分线：350
→ 三校生高考 / 专升本 → 本科 / 专科
初中 4年 → 中考 ↗ 普高 3年 → 高考 → 本科/专科
初中 4年 → 中考 ↘ 中本贯通 3+4年 → 本科
初中 4年 → 中考 ↘ 五年/中高职 5年 → 大专 → 专升本→本科
以上三条路径均可最终获得本科学历。中本贯通免高考直达本科，是"曲线救国"的优质选择。
